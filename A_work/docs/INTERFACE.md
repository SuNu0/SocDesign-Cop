## 文件与层次

`compute_lane` 包含 `dot64_mac` 和 `bias_requant`。B 可直接实例化 lane，
也可按相同契约独立连接两个子模块。均为可综合 SystemVerilog，无厂商原语。

| 信号 | 方向（相对 lane） | 位宽 | 语义 |
|---|---|---:|---|
| clk | 输入 | 1 | 目标平台 150 MHz；实际 ASIC 时序由 C 验证 |
| rst_n | 输入 | 1 | 异步低有效；B/C 负责复位释放同步 |
| in_valid / in_ready | 输入 / 输出 | 1 / 1 | 同一上升沿二者均为 1 才接受一对操作数 |
| in_x / in_w | 输入 | 16 / 16 | 有符号补码，按 k=0..63 依次提供 |
| in_bias | 输入 | 40 | 已对齐到乘积尺度的有符号偏置，仅首对接受时采样 |
| in_shift | 输入 | 6 | 右移量 0..63，仅首对接受时采样 |
| out_valid / out_ready | 输出 / 输入 | 1 / 1 | 上升沿均为 1 才传走一个输出 |
| out_data | 输出 | 16 | 舍入、饱和后的有符号补码 |

每连续累计 64 次输入接受构成一个点积，无额外 start/last。
输入间隔任意，不会因 valid=0 或 ready=0 推进计数。发送方 valid=1 而 ready=0 时，
必须保持 valid 和本次输入数据；输出端同理。复位可中止部分点积及尚未取走的结果，
复位后从新的第 1 对输入开始。没有独立 abort、busy 或任务 ID；需要时由 B 在外层实现。
协议非法的 63 对/65 对输入不会自动报错，B 的调度与测试必须保证任务边界。

无输入停顿和下游反压时，每个点积接受 64 对数据，MAC 结果排出需要 1 拍，
新点积最早每 65 拍开始一次。第 64 对接受后，MAC 在下一拍向偏置模块交接，
偏置模块再依次完成取绝对值、移位、舍入饱和三个阶段，因此 lane 在其后的第 4 拍置 out_valid。
偏置模块是单事务多拍状态机，等待输出取走后才接受下一事务，不保证每拍输入吞吐。
不要假定反压下固定延迟；必须按握手收结果。

## 数值契约

每层 `formats.json` 固定 fx、fw、fy、shift，真实值 = 编码 × 2^(-f)。

1. 输入与权重分别量化为 signed16；零点固定为 0。
2. 乘积 signed32；每次接受后做 signed40 加法。40 位累加按补码截断定义；
   对 64 个 signed16 乘积，所有前缀和均可放入 signed38，因此合法 dot64 不会溢出 signed40。
3. 偏置编码为 `round_away(b × 2^(fx+fw))`，存为 signed40；真实模型脚本检查偏置范围。
4. MAC 与偏置先符号扩展，使用 signed41 相加，**这一步不截回 40 位**。
5. `shift = fx+fw-fy`。按绝对值加 2^(shift-1) 再右移，恢复符号，实现最近舍入、正负半值均远离零。
   shift=0 不添加舍入偏移。
6. 最后饱和到 [-32768,32767]，输出尺度为 2^(-fy)。

fx/fw/fy 从训练划分的无梯度标定得到，验证划分只做评估；禁止按测试划分调参。
当前候选每层一个尺度，无每通道尺度，无非零 zero-point。更改配置必须重新生成向量并回归。

## 矩阵布局与字节序

X[99,64]、W[64,256]、Y[99,256] 均按 C row-major 顺序。
Keras Dense kernel 原本就是 [64,256]，当前指定模型无需转置。

| 文件 | 元素下标 | 二进制存储 | 单层字节数 |
|---|---|---|---:|
| x.bin | i*64+k | little-endian signed16 | 12672 |
| w.bin | k*256+j | little-endian signed16 | 32768 |
| b.bin | j | signed40 符号扩展到 little-endian signed64 | 2048 |
| y.bin | i*256+j | little-endian signed16 | 50688 |

这四份数据共 98176 字节。地址分配、对齐、总线字节使能、寄存器位定义由 C 依据
正式平台冻结。上述布局是可测试的交接候选，尚未以真实 SoC 总线验证。
`.hex` 是逐元素补码文本，bias 每项 10 位十六进制，不等同于 b.bin 的 8 字节容器。
`pack_vectors.py` 对二进制做逐项解码回读，保存每份文件的 SHA-256。
