# 本科生前馈第一线性层加速器：SystemVerilog 首版

实现完整尺寸 `Y[99,256] = X[99,64] × W[64,256] + b[256]`。
没有缩小矩阵，没有把乘累加交给 Python 或测试平台代算。
Python 只生成测试输入与独立参考答案，RTL 通过总线接收数据、执行计算并写回内部结果 SRAM。

## 一键仿真

依赖 Python 3、NumPy、Icarus Verilog 12 或兼容版本。`iverilog` 和 `vvp` 需在 PATH 中。
在本工程目录执行：

```powershell
python scripts/run_sim.py
```

默认测试 12 套完整尺寸数据。快速运行一套：

```powershell
python scripts/run_sim.py --layers 1
```

生成控制波形：

```powershell
python scripts/run_sim.py --waves
```

波形包含时钟、总线握手和核心状态，不包含整块 SRAM。12 层长仿真的 VCD 仍可能较大。
可用 GTKWave 打开 `build/ffn_control.vcd`。

## 硬件结构

```text
E203 / 测试平台
       │ 32位 ICB 风格从接口
       ├── 控制与状态寄存器
       ├── X SRAM（99×64，行优先）───────┐
       ├── W SRAM（16个并行银行）─────┐ │
       ├── b SRAM ──────────────────┐│ │
       │                            ↓↓ ↓
       │                      16路乘法 + 独立40位累加器
       │                            │
       │                      舍入 / 饱和 / 结果暂存
       └── Y SRAM（99×256，行优先）←──┘
```

同一拍广播一个输入 `X[i,k]`，并行读取 `W[k,j…j+15]`，计算同一行的 16 个输出。
每个输出累加 64 项。每行分 16 组，99 行共 1,584 组。
12 层使用同一套硬件，软件逐次完整装载各层的 `X/W/b`；`LAYER_TAG` 只记录层号，
不会自动产生或选择模型参数。各层真实输入必须分别从指定模型提取，不能直接把 99×256 输出接到下一层的 99×64 输入。

### 同步存储和流水线

每组操作顺序：

1. `S_BIAS`：16 个偏置顺序读取，另加 1 拍同步读取收尾，共 17 拍。
2. `S_MAC`：同步读取 → 注册乘积 → 40 位累加，共 64+2=66 拍。
3. `S_ROUND`：16 路同时舍入、饱和并暂存，共 1 拍。
4. `S_WRITE`：单端口 Y SRAM 每拍写一个数，共 16 拍。

总计每组 100 拍，整层 `1,584×100 = 158,400` 拍。
`CYCLES` 从接受 START 后的第一个活动拍开始，计入最后一个输出 SRAM 写入拍；
不计入 START 接受拍或 CPU 装载/读回时间。
按 150 MHz 换算为 **1.056 ms**，是该 RTL 的周期换算值，尚未进行工艺库时序收敛。

测试平台的 `host_end_to_end_cycles` 还包含全部输入/参数总线装载、启动、轮询、
输出总线读回及少量自检读事务。它反映此测试平台的总线主机行为，
没有建模真实 E203 指令执行或平台总线仲裁，不能当作比赛吞吐量结果。
本版无 DMA，共享 SRAM → 内部 SRAM 和内部 Y → 共享 SRAM 的搬运要由处理器驱动实现。

### SRAM 宏容量

| 存储 | 有效元素数 | 16位宏组合 | 实际容量 |
|---|---:|---|---:|
| X | 6,336 | 2 × 4096 深度 | 16 KiB |
| W | 16,384 | 16 × 1024 深度 | 32 KiB |
| b | 256 | 2 × 128 深度 | 0.5 KiB |
| Y | 25,344 | 7 × 4096 深度 | 56 KiB |
| 合计 | 48,320 | 27 个单端口宏 | **104.5 KiB** |

SRAM 抽象是同步读写、无数组复位的可综合 RTL。
正式集成时必须换成组委会提供的 16×128/1024/4096 宏及其模型，核对端口极性、
读延迟、时序和功耗库。当前组合只对应容量规格，不代表完成宏映射或通过面积预算。

## 数值格式

输入、权重、偏置和输出均为 **有符号16位，8位小数**，本文称 Q8.8。
符号位包含在高8位中，范围 `[-128,127.99609375]`，实数值为 `signed_integer/256`。

```text
P[k]    = signed16(X[k]) × signed16(W[k])       // 有符号32位，16位小数
ACC     = sum(P[0…63]) + (signed16(b) << 8)    // 有符号40位，16位小数
ROUNDED = sign(ACC) × floor((abs(ACC)+128)/256)
Y       = clip(ROUNDED, -32768, 32767)          // 有符号16位，8位小数
```

舍入为最接近、半值远离零；对完整点积和偏置合计只舍入一次。
偏置在硬件中先对齐后预置到累加器，与最后加偏置在此精确整数范围内等价。
64 项最大绝对乘积约为 `2^36`，加上偏置仍远小于40位累加器上限 `2^39−1`，
因此对任何合法16位输入均不会发生累加回绕；输出允许饱和并通过 `SATURATIONS` 计数。

固定 Q8.8 是首版数值方案；需要在真实预训练参数和允许的标定数据上验证误差后再决定是否调整。
构造向量的逐位一致性不能证明真实模型的 3% NRMSE 门槛。

## 接口与地址表

从接口采用 E203 ICB 常用的 `cmd_valid/ready` 和 `rsp_valid/ready` 握手。
最多一个未完成事务。响应保持到被接受，支持响应反压。
本模块接收 **外设内部的局部字节地址**；平台须先匹配外设地址范围，再减去映射基址。
命令握手表示事务被接受，不表示写入成功；主机必须检查响应 `rsp_err`。

全部访问32位对齐。写操作只接受 `wmask=4'b1111`；未映射、未对齐、非法写入返回错误且不修改状态。
空闲时内部数据存储均可读，X/W/b 可写、Y 只读。运行时所有数据窗口访问和重复 START 均返回错误。
状态寄存器运行时可读。

| 局部偏移 | 名称 | 语义 |
|---|---|---|
| 0x0000 | CONTROL | 写bit0=START，bit1=清除DONE/IRQ；读返回0；其他位写1报错 |
| 0x0004 | STATUS | 只读：bit0=BUSY，bit1=DONE |
| 0x0008 | CYCLES | 只读：当前/最近任务的核心周期 |
| 0x000C | MAC_COUNT | 只读：1,622,016 |
| 0x0010/14/18 | M/K/N | 只读：99/64/256 |
| 0x001C | FORMAT | 只读：0x0810，高8位为小数位数8，低8位为数据宽度16 |
| 0x0020 | LAYER_TAG | 空闲时可写0…11；只用于标记 |
| 0x0024 | SATURATIONS | 只读：本任务饱和输出数量 |
| 0x0028 | VERSION | 只读：0x00010000 |
| 0x10000…0x162FC | X | 6,336 个32位地址槽，每槽低16位一个元素 |
| 0x20000…0x2FFFC | W | 16,384 个32位地址槽，每槽低16位一个元素 |
| 0x30000…0x303FC | b | 256 个32位地址槽，每槽低16位一个元素 |
| 0x40000…0x58BFC | Y | 25,344 个只读32位地址槽 |

数据窗口读取时，将16位值符号扩展到32位；写入只取低16位。
矩阵的软件视图全部为行优先：`X[i*64+k]`、`W[k*256+j]`、`Y[i*256+j]`。
权重硬件内部拆银行：`bank=j%16`，`bank_addr=k*16+j/16`。
外设窗口建议至少保留 `0x60000` 字节；32位一个元素的地址布局会增加总线流量，
SRAM内部仍是16位。后续可以加入打包传输或 DMA 优化。

DONE 保持到写 CONTROL.bit1 或接受下一次 START。`o_irq=DONE` 为电平中断。
`rst_n` 异步低有效，中止当前任务、清状态与计数，不清SRAM；复位释放应由平台同步。
没有数据装载有效位跟踪：驱动必须在每次 START 前完整装载合法 X/W/b。
输出只有 DONE=1 后才代表本次完整结果；复位后旧输出无效。
软件访问需串行化，本版不支持多个主机同时提交任务。

## 验证范围

`tb/tb_ffn_accel.sv` 不使用层次化方式写入DUT存储器；所有数据通过外部总线进入。
测试平台只用层次化信号观察运行状态和生成波形。

- 12 套输入各执行一次完整矩阵运算，每套比较全部25,344个32位符号扩展读回结果。
- 第0套：全零输入和带正负边界值的偏置，检查偏置广播。
- 第1套：全部64项的满幅正负乘积、超过32位的累加、抵消与输出饱和。
- 第2套：正负半LSB舍入边界。
- 第3…11套：独立生成的稠密有符号随机输入、权重和偏置。
- 异常地址、地址边界、未对齐、非法字节掩码、只读写入。
- 寄存器和同步SRAM读响应的等待稳定性。
- 运行中重复启动、运行中读写数据/层号时的错误返回。
- 读事务中复位、计算中复位中止、12次不复位的连续任务。
- DONE/IRQ应答、饱和计数、固定计算周期数。

测试时钟为 `#3.333 ns` 半周期，约150 MHz，功能仿真没有标准单元/宏延迟。
这不代替150 MHz的静态时序检查。

## 替换为真实模型数据

按赛题规定的仓库版本和预训练权重，在电脑上提取某层前馈第一线性层的：

```python
np.savez("layer0.npz", X=X, W=W, b=b)
# X.shape == (99,64), W.shape == (64,256), b.shape == (256,)
```

若原框架权重保存成 `[out_features,in_features]`，提取时需转置为 `[64,256]`。
随后运行：

```powershell
python scripts/convert_npz.py layer0.npz build/real_vectors --layer 0
python scripts/run_sim.py --layers 1 --vectors build/real_vectors
```

转换脚本按本文规则编码，生成输入HEX、整数模型参考输出、饱和数量和单输入浮点误差诊断。
输出参考答案仅供测试平台比较，不会被加速器读取。
真实模型整体精度还需按赛题数据划分、600条评测样本与12层分别汇总规则评测；
不得使用测试划分来调整量化配置。本工程没有下载权重或执行模型提取。
