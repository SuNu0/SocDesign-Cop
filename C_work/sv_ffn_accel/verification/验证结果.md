# 首版验证结果

验证日期：2026-10-18（Asia/Shanghai）。

本报告记录一次实际执行的 Icarus Verilog 总线级功能仿真，详细日志见同目录
`simulation.log`，机器可读结果见 `summary.json`。

| 项目 | 结果 |
|---|---|
| 仿真器 | Icarus Verilog 12.0 devel |
| 输入 / 权重 / 输出 | 99×64 / 64×256 / 99×256 |
| 完整矩阵任务 | 12 次，每次更换完整输入、权重和偏置 |
| 全部输出比较 | **304,128 个，零差异** |
| 核心周期 | 每次 **158,400 拍** |
| 核心周期按150 MHz换算 | 每次 **1.056 ms** |
| 测试平台端到端周期 | 每次 **328,739 拍** |
| 测试平台端到端按150 MHz换算 | 每次约 **2.1916 ms** |
| 满幅正负累加与饱和测试 | 通过；12,672个饱和输出，计数逐项匹配 |
| 正负半LSB舍入、零输入与偏置广播 | 通过 |
| 总线地址错误、反压、忙碌访问 | 通过 |
| 读响应中复位、计算中复位与连续任务 | 通过 |
| C驱动 | 主机GCC的C11严格语法检查通过；未运行于E203 |
| NPZ转换脚本 | 构造输入往返转换后X/W/b/Y/sat五类HEX均一致 |

测试平台端到端窗口包括装载、启动、轮询、读回和自检事务。
它没有真实E203的指令执行、共享SRAM访问或平台总线争用，不是比赛吞吐量成绩。

全部12套数据都是构造测试向量，不是指定预训练模型的12层提取数据。
没有验证真实模型3%误差门槛，也没有完成指定SoC集成、实际工艺综合、
150 MHz时序收敛、面积或功耗核验。

复现命令（在工程根目录）：

```powershell
python scripts/run_sim.py --layers 12 --waves
```

`source_sha256` 记录本次仿真的RTL和测试平台文件哈希。
`summary.json` 中的 wall_seconds 是仿真器在主机上运行的实际墙钟时间，
与芯片执行时间无关。

压缩交付包包含源码、数值模型、测试平台、驱动、文档和验证日志；
大体积VCD与可重建HEX未打包，运行上述命令即可重新生成。
