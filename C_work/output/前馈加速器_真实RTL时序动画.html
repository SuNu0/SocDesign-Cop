01 / TWO STATE MACHINES
总线在响应，核心也可以在计算。
H_IDLE → H_READ → H_RESPONSE 管理主机请求；S_IDLE → S_BIAS → S_MAC → S_ROUND → S_WRITE 管理计算。两套状态机独立。cmd_ready 由总线状态决定，不等于 !BUSY。核心忙时仍能读取 STATUS，数据窗口访问则返回 rsp_err。
02 / EXACTLY 100 CLOCKS
64 项点积，为什么一组用 100 拍？
偏置顺序读取 17 拍；同步读、乘法、累加流水线共 66 拍；舍入暂存 1 拍；单端口结果 SRAM 顺序写入 16 拍。共100拍，得到16个输出。

03 / THE NBA RULE
同一个沿，右边读取的都是旧值。
例如 product <= x * w 与 acc <= acc + product 同沿执行，累加器读到的是上一拍的 product。因此读第k项、乘第k−1项、累加第k−2项能够同时发生。右侧沿后值显示本拍更新结果。
