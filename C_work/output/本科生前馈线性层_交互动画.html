01 / INPUT

输入从哪里来？

1 秒语音 → 98×40 MFCC → 投影、分类 token 与位置编码 → 99×64 编码器输入。本科加速器实际接收的是各层经过注意力、残差与第一处 LayerNorm 后的前馈输入。这些输入由电脑离线提取。

02 / IMPLEMENTATION

数学之外，还要实现什么？

参数装载、输入缓冲、计算调度、结果写回，以及 E203 接口、驱动、仿真和逻辑综合。完整任务计时包括数据装载和结果写回。工作频率要求为 150 MHz，加速器面积上限为 2.25 mm²。
