# 并行量化动画小课堂

双击同目录的 `index.html` 即可使用，不需要安装软件、启动服务或联网。

从“播放讲解”开始，或点击左侧六个章节。可暂停、切换速度，使用左右方向键切换章节、空格播放或暂停；输入控件获得焦点时保留其原生键盘操作。

可以尝试：

1. 点击二进制开关，观察 `[6:0]` 如何表示 0～127。
2. 点击数组中的格子，观察同一条通道的数据归属。
3. 查看 generate 展开的并行量化逻辑，切换 4 / 16 通道。
4. 修改 40 位累加器原始整数，检查舍入、上下限、17 位输出和负数补码。
5. 切换正常 / 混合 / 全部饱和，观察组合求和结果。
6. 查看索引、发起进度、valid 与 last 的工程含义。

项目实际使用 16 通道；4 通道是缩小的教学示例。量化行为依据 `sv_ffn_accel/rtl/ffn_numeric_pkg.sv`：除以 256、就近取整（半值远离零）、饱和到 −32768～32767。页面显示的是整数编码。

点击页面上方的“手算模式”可进入练习：每条通道依次填写精确商、舍入整数、限幅整数、饱和标志、17 位拼接结果，最后汇总整组饱和数量。答案默认隐藏，每步提供检查、提示和完整手算过程。

可以使用当前动画数据，或切换简单练习、边界练习、原始示例，也可以自定义任一通道的 40 位整数。二进制答案支持用空格、下划线或 `|` 分隔；数值答案支持千位逗号。查看参考解答后会标记已参考，不会自动填入答案或计入已核对项目。

切换模式和通道会保留草稿。更换练习会清空整组答题；改变一个通道的输入只清空该通道及整组计数；切换 4/16 通道会保留通道草稿、清空整组计数。草稿仅保存在当前页面内存中，刷新或关闭后清空。

流动动画和逐项高亮仅为讲解顺序，不表示时钟周期、组合逻辑的真实延迟或综合后的具体加法器结构。寄存器更新和流水线行为结合 `ffn_accel.sv` 后面的时序逻辑解释。

文件自包含，不依赖 CDN、外部字体或第三方库。
