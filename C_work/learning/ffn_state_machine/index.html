动画对应的硬件规则、参数和代码来源
这是按照所给 RTL 编写的确定性教学模型，不是 HDL 仿真器。数值输入与权重是用于观察正负数和饱和的教学样本，没有修改工程文件。乘加、同步 SRAM 返回、valid/last 延迟、状态切换与非阻塞赋值按所给代码建模。
  • 工程参数：ROWS=99、分组数=16、LANES=16、INNER=64，输出列数为 16×16=256。入门模型把对应数量缩为 2、2、4、4，状态与流水线规则相同。右侧源代码保留工程原文。
  • 每组周期数 = 偏置读取 N+1 拍 + 乘加 K+2 拍 + 结果保存 1 拍 + 写回 N 拍。入门模型每组 16 拍、全任务 64 个 busy 时钟；工程每组 100 拍、全任务 158400 个 busy 时钟。接收启动的时钟沿不计入 cycle_count。
  • 一次时钟沿只执行沿前 state 对应的分支。所有 <= 的右侧使用旧值，并在沿后一起更新。图中的流动动画只表示数据关系，不表示芯片实际传播时间。
  • rst_n 的下降沿立即复位控制与数据寄存器，Y SRAM 本身没有复位。按钮“重开演示”则会清空全部教学模型数据。
  • done 是保持型标志，回到 S_IDLE 后不会自行变成 0。clear_done、下一次启动或复位可以清除它。如果 clear_done 与最终完成同拍，分支中较后的 done<=1 生效。
  • 量化规则：累加器整数除以 256、就近取整（半值远离零）、饱和到 −32768～32767。输出缓冲区实际保存 16 位补码；页面按有符号整数显示。
