# FFN 状态机动画

双击 `index.html`，无需服务、安装或联网。文件夹中的 HTML、CSS、JavaScript 文件须放在一起。

页面默认以时序图演示，也可切换到“状态路线”。点击“生成一组完整时序”，会从头执行一组计算，并选中第一次累加的时钟沿：橙色箭头连接同一个 k 的读取、乘法和累加。点击图中任一列即可回看该拍，寄存器旧值/新值、执行动作、说明与源码高亮同步切换，机器实际进度不会倒退。“单步时钟”或“跟随最新”返回最新事件。

可以切换状态控制、偏置读取、乘加流水线、量化写回、全部信号五种组合，选择观察的通道、窗口长度和每拍宽度。横向滚动查看时间，使用窗口滑块和更早/更晚按钮翻看记录；全部信号支持纵向滚动。保留最近 512 个事件，适合观察局部时序。

实线高低表示 1/0，多位数据用带值的框表示；寄存器在上升沿后更新，start_event / clear_done 输入脉冲跨越被采样的上升沿。“本拍读取/乘法/累加”是事件注释，不是连续信号。异步复位与释放记在相邻上升沿之间，寄存器复位变化无需等待时钟；这些相对位置和间隔仅为教学示意，不代表真实纳秒或传播延迟。

推荐按这个顺序探索：

1. 默认使用入门模型，点击“发出启动”，再点击“单步时钟”。对照沿前/沿后表格，观察一次时钟沿只执行旧状态分支。
2. 点击“运行到下一状态”，快速经历 S_IDLE → S_BIAS → S_MAC → S_ROUND → S_WRITE。
3. 在“看关键时刻”中定位偏置最后等待拍、乘加流水线排空、组切换、行切换或最后完成之前的一拍，再单步观察。
4. 切换观察的 lane，查看相乘、累加和输出值；用最近 12 拍表格对照同一拍不同阶段的 k 编号。
5. 用“拉低复位 / 释放复位”观察异步复位；用“清除 done”观察完成标志保持与清除。
6. 切换到工程参数，查看 99 行、16 组、16 通道、64 项乘加的完整路径。

入门模型为 2 行、2 组、4 通道、4 项；代码面板仍保留工程原文，并提示教学参数替换。入门每组 16 个 busy 时钟、全任务 64 个；工程每组 100 个、全任务 158400 个。启动沿不计入 cycle_count。

模型复现给定 RTL 的同步 SRAM 数据返回、非阻塞赋值、valid/last 流水、偏置尺度对齐、量化、饱和统计和写回顺序。样例输入/权重用于教学；模型不替代 HDL 仿真。

寄存器在异步复位时立即清零，输出 SRAM 保留数据；“重开演示”会清空整个教学模型。数据使用有符号整数编码展示，实际 16 位输出使用补码。

源代码：`sv_ffn_accel/rtl/ffn_accel.sv:214–285`。`simulator.js` 是时钟模型，`waveform.js` 绘制交互时序图，`app.js` 控制视图和交互，`styles.css` 为页面样式。
