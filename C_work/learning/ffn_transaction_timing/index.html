读时序为什么有两种？

寄存器读和写事务在命令接受沿后产生响应。同步SRAM读先进入 H_READ，下一沿才寄存响应。响应产生后，还要在 rsp_valid && rsp_ready 的上升沿被主机接收。

查看两类事务的最短顺序

寄存器读 / 写：E0接受命令 → E1接收响应。
SRAM读：E0接受命令 → E1产生响应 → E2接收响应。
以上假设主机及时置rsp_ready；本页为便于观看，在事务前后保留空闲拍。

哪些访问在运行中仍然允许？

所有寄存器仍可读；CONTROL可以写0或2。数据窗口的所有读写、修改LAYER_TAG、再次START都会报错。cmd_ready只代表可接收命令，访问是否成功看 rsp_err。
