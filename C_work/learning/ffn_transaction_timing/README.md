# FFN加速器事务时序图鉴

用Chrome或Edge打开本目录的 `index.html`，也可以双击 `打开演示.cmd`。
HTML已内嵌脚本与全部采样，可离线运行，也可以单独复制到其他电脑使用。

## 内容

96个场景、719个真实采样上升沿，按8类组织：

| 类别 | 场景数 | 内容 |
|---|---:|---|
| 数据写入 | 6 | X、W、b的首末元素；低16位写入；权重不同bank |
| 数据读回 | 8 | X、W、b、Y的首末元素；同步读取与符号扩展 |
| 寄存器读取 | 11 | 所有已映射寄存器在空闲时的读取 |
| 控制与层号 | 8 | CONTROL的0/1/2/3、清DONE、保留DONE时再启动、层号0与11 |
| 握手与等待 | 8 | 寄存器读、SRAM读、写、错误与START响应反压，下一命令等READY，无VALID、读掩码 |
| 错误与保护 | 21 | 写所有只读寄存器、写Y、未映射、未对齐、非法写掩码、层号与控制位非法、窗口越界 |
| 忙时访问 | 24 | 全部寄存器读取、四个数据窗口的读写拒绝、重复START与层号写入拒绝、CONTROL=0/2 |
| 完成与复位 | 10 | 最后写回、DONE/IRQ、完成状态与计数、清除后状态、读等待/响应等待/计算中的复位 |

“每个事务”按接口定义的操作和不同结果展开。矩阵中间的普通元素遵循同一读写规则，示例使用首末地址；非法地址与掩码展示代表性条件，不逐个枚举所有32位地址或数据组合。

## 页面操作

- 在左侧按事务名称、寄存器或十六进制地址搜索，也可按类别筛选。
- 点击播放立即前进一拍；支持暂停、重播、速度、前后单步和进度拖动。
- 点击“命令握手”“响应产生”“响应握手”等按钮，直接跳到关键沿。
- 波形每格一拍：格中央是上升沿，左半显示沿前值，右半显示沿后值。
- 握手由沿前的VALID和READY决定；右侧逐项对照同一个沿的前后变化。
- 沿后是在上升沿后1 ps采样，等待非阻塞赋值完成，不代表多出一拍。
- 波形中的C、R、D分别标记命令握手、响应握手、完成事件。未知值显示X。
- 可切换仅总线、本场景关键信号、全部内部信号。横向滚动时信号名称保持可见。
- 空格播放/暂停，左右方向键逐拍，Home/End跳到首尾；输入框和按钮获得焦点时保留原生键盘行为。

演示使用10 ns时钟以便阅读。目标150 MHz的工程约束与工艺实现另行验证；这些波形显示功能时序，不表示标准单元或SRAM宏的传播延迟。

## 采样来源与复现

直接实例化 `../../sv_ffn_accel/rtl/` 中未修改的3个RTL文件。
所有X/W/b通过外部总线完整初始化，随后执行目录中的实际事务。未通过层次化写入篡改内部存储或状态。
完成场景执行了完整158400拍任务；再次START前的旧DONE来自另一个完整任务。
不同场景前后可能有未展示的初始化或计算过程；每个场景内部的采样沿连续，页面显示全局仿真沿号与时间。

在本目录执行：

```powershell
python build_demo.py
```

需要Python 3、Icarus Verilog的 `iverilog` 与 `vvp`，不需要NumPy。
只改页面时可复用已验证数据：

```powershell
python build_demo.py --pack-only
```

打包会核对RTL与采样测试平台的SHA-256，拒绝使用不匹配的旧数据。
如果修改了场景生成代码，请执行完整重建。

| 文件 | 用途 |
|---|---|
| `index.html` | 最终单文件演示 |
| `app.js` / `template.html` | 播放、波形绘制、解释和页面样式源码 |
| `build_demo.py` | 生成场景、生成测试平台、运行仿真、校验并打包 |
| `capture/tb_transactions.sv` | 实际采样测试平台 |
| `capture/trace.jsonl` | 原始沿前/沿后采样，保留未知值 |
| `capture/data.json` | 场景说明与解析后的采样数据 |
| `capture/verification.json` | 校验结果与源码哈希 |
| `check_browser.cjs` | 当前工作站的Edge/Chrome交互检查脚本，Playwright路径按本机环境指定 |
| `preview/browser_checks.json` | 浏览器检查结果 |

校验包含全部事务的预期响应、读数据、同步SRAM多一拍、反压稳定、单个在途事务、START状态和158400拍末写回完成。既有RTL功能回归无需因此页面修改而改变。

## 数值示例

数据均是构造数据。主要设置为X[0,0]=1.5、W[0,0]=−1、b[0]=0.5，得到Y[0,0]=−1；末元素示例得到Y[98,255]=0.5。
输入/权重/偏置/输出的整数编码均为实数乘256。演示没有评测预训练模型精度。
